## ✦ Featured Project

### Hands-Free Recipe Navigator

A collaborative interaction design project exploring how hand gestures and audio instructions can make navigating recipes easier while cooking.

The project combines gesture-based interaction, recipe browsing, and hands-free navigation to reduce the need to touch a screen while preparing food. My contributions focused on **visual design, wireframing, mockups, documentation, presentation, and collaborative development**.

- **Explore the prototype:** [Hands-Free Recipe Navigator](https://hands-free-recipe-navigator.onrender.com/)
- **Focus areas:** Interaction Design, UX/UI, Prototyping, and Emerging Technology
